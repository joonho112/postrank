When domains can be graded separately

Source: vignettes/mdomain-decisions.Rmd
mdomain-decisions.Rmd

A multidomain report assigns each unit one grade in each domain. Smaller grade labels mean higher reported priority within that domain. A tie withholds a direction; it does not assert that the latent targets are equal. This article explains when separate domain choices solve the reporting problem, and when the dependence between domains changes the chosen profile. The executable examples use small, independently specified synthetic inputs, run offline, and need no optimization backend. The exact and MCMC examples run when the suggested package gmp is installed.

Additive loss and separate choices

Let GdG_d be the grade column in domain dd, FdF_d the number of false disclosed directions in a posterior state, and TdT_d the number of withheld pairs. A strict direction at latent equality is false. With nn original units, M=(n2)M = {n \choose 2} remains the loss denominator, even when a card withholds some comparisons. The additive expected loss is

R(G)=∑dwd{E(Fd)+τdTd}/M. R(G) = \sum_d w_d\{E(F_d) + \tau_d T_d\}/M.

Its domain terms depend only on the corresponding marginal law. Suppose the declared family is a Cartesian product of domain banks and every constraint is domain specific, such as structural equality, grade caps, or an expected-error guard. The feasible family is then also a Cartesian product. Minimizing each weighted domain term separately minimizes the sum; combining the complete sets of those minimizers gives every minimum in that product. For a zero-weight domain, every feasible column minimizes its weighted term. This conclusion does not require independent posterior domains. A common-grade requirement or another constraint linking columns would require a different argument.

A joint protection requirement changes the feasible set. For example, write NdN_d for the number of disclosed pairs in the specified scope and require

J(G)=P{at least one d has Fd>tdNd}≤α. J(G) = P\{\text{at least one }d\text{ has }F_d > t_d N_d\} \leq \alpha.

This is a union within the same posterior state. Dependence can change its probability while leaving the marginal errors and additive loss unchanged. If Nd=0N_d=0, that domain’s exceedance event is structurally false; the corresponding error fraction is undefined rather than a measured zero.

Two units, two domains, unchanged marginal errors

Units A and B have binary priority values. In a normal state A is above B in both domains. A reversal exchanges their values. The two complete finite laws below differ only in how their reversals occur together:

Law Normal in both Reverse domain one only Reverse domain two only Reverse both
Coincident 9/10 0 0 1/10
Disjoint 8/10 1/10 1/10 0

In either domain of either law, reporting A above B has error probability 1/10. Set equal domain weights, tie loss tau = "1/4", strict threshold t = "0", and joint cap alpha = "3/20". Character fractions preserve these exact policy values.

units <- c("A", "B")
domains <- c("one", "two")
targets <- setNames(lapply(domains, function(d) list(
  definition = paste("Fictional priority in domain", d),
  units = "arbitrary priority units", orientation = "larger_is_higher",
  equality_classes = units,
  equality_provenance = "A and B are distinct modeled targets.")), domains)

# Each row specifies the reversals in one complete joint state.
make_states <- function(reverse, ids) {
  x <- array(0, c(nrow(reverse), 2L, 2L),
    dimnames = list(ids, units, domains))
  for (d in seq_along(domains)) {
    x[, "A", d] <- ifelse(reverse[, d], 1, 2)
    x[, "B", d] <- ifelse(reverse[, d], 2, 1)
  }
  x
}
make_law <- function(id, reverse, masses) {
  postrank_mdomain_input(
    make_states(reverse, paste0(id, "-", seq_len(nrow(reverse)))),
    targets = targets,
    provenance = list(input_id = id, law_id = id, proper_law = TRUE,
      joint_generation = "Complete finite support authored in this article.",
      sampling_assumptions = list(
        finite_support_origin = "All support states and exact masses listed here.")),
    representation = "exact_finite_law", masses = masses)
}
laws <- list(
  coincident = make_law("coincident",
    rbind(c(FALSE, FALSE), c(TRUE, TRUE)), c("9/10", "1/10")),
  disjoint = make_law("disjoint",
    rbind(c(FALSE, FALSE), c(TRUE, FALSE), c(FALSE, TRUE)),
    c("8/10", "1/10", "1/10")))
policy <- postrank_mdomain_decision(tau = "1/4", t = "0", alpha = "3/20")

Declare three columns per domain: withhold, A above B, and B above A. Their full Cartesian product has nine candidates. No direction is omitted from this stated bank. The optimum claims below concern this bank.

columns <- list(withhold = c(A = 1L, B = 1L),
  A_above_B = c(A = 1L, B = 2L), B_above_A = c(A = 2L, B = 1L))

  columns = list(one = columns, two = columns), max_actions = 9L)

  postrank_mdomain_solve(laws[[id]], families[[id]], policy, max_actions = 9L))
names(fits) <- names(laws)

The dual report A above B has expected loss 1/10 under either law. Its joint error probability is 1/10 for coincident reversals and 1/5 for disjoint reversals. Thus it passes the 3/20 cap only under the coincident law. The disjoint law has two tied optima: report A above B in either one domain and withhold the other. Each has loss (1/2)(1/10+1/4)=7/40(1/2)(1/10 + 1/4) = 7/40 and joint probability 1/10.

Disabling joint protection recovers the separate-choice result: the dual report is optimal for both laws. Marginal expected errors and expected loss did not change; the union constraint is what coupled the feasible choices. An arbitrary pairing or permutation of separate marginal draws cannot establish which joint law applies.

separable_policy <- postrank_mdomain_decision(tau = "1/4", t = NULL)

Reading a frozen 40-site illustration

The installed JSON below is a small, frozen output illustration for 40 fictional sites from JoonHo Lee’s Need-Based Prekindergarten Funding tutorial. Domain S describes student-composition economic need and domain C describes catchment-community economic need; both use larger values for higher need. These are distinct target definitions, including conditional predictive S targets for new sites. Sharing a community target does not identify student targets: S05/S06 and S21/S22 are declared C identity pairs, while all 40 S targets are distinct. The original all-pair denominator is 780.

The original calculation used 8,000 retained states from chains 1–2 for selection, a declared seven-column bank per domain (49 candidate cards), and a fixed-card diagnostic replay on 8,000 states from chains 3–4. Ordering the candidate columns used the selection states. The two cases share equal weights, tau = "1/10", q = "1/20" and alpha = "1/20"; the wide case changes t from 5% to 10%. Their distinct case IDs preserve that difference.

This vignette reads the frozen grades and summary counts. It does not run the original 40-site analysis, load its posterior archive, select a new card, or perform a new validation. The public reproducibility appendix describes the external tutorial workflow. Source commit, relative input path, hash and changes are recorded in the JSON; none is an installation-time dependency. Reproducing the multidomain analysis separately requires the original identified joint states, target/equality map, chain allocation and the stated 7-by-7 candidate design, rather than these summaries alone.

The primary card withholds every S comparison and discloses 500 C comparisons in grades of size 10, 10 and 20. Its selection risk is 170039/2496000. Strict 5% exceedance among 500 disclosed pairs requires at least 26 errors; exactly 25 does not exceed the threshold. No selection state exceeded the threshold, although 1,871 had at least one error. Hence J = 0 describes zero observed exceedances at that threshold, and does not say that the card made no errors.

The wide card discloses 300 S pairs and 500 C pairs. Its selection risk is 716341/12480000 and its selection exceedance rate is 266/8000 = 133/4000. The same fixed card gives 229/8000 in the diagnostic chains. Exact fractions here mean exact arithmetic for the represented equal-weight empirical measure. Splitting chains and recording disjoint state IDs does not establish independence or an iid numerical certificate for the intended posterior.

Inspecting MCMC history for a fixed report

The following independent, tiny synthetic example demonstrates the MCMC assessment API. It generates two short Markov histories of unequal lengths. The two-state transition probabilities are 1/10 from normal to reversed and 2/5 in reverse; the stationary reversal probability is 1/5. A whole state reverses both domains together. Original chain order and iteration numbers are retained. These short histories illustrate diagnostic fields, not a recommended simulation length or evidence about the 40-site source.

simulate_chain <- function(n) {
  z <- logical(n)
  z[1L] <- stats::runif(1) < 1/5
  for (i in 2:n)
    z[i] <- if (z[i - 1L]) stats::runif(1) >= 2/5 else stats::runif(1) < 1/10
  z
}
set.seed(1202)
chains <- list(chain_A = simulate_chain(24L), chain_B = simulate_chain(31L))
z <- unlist(chains, use.names = FALSE)
history <- data.frame(source_index = seq_along(z),
  chain_id = rep(names(chains), lengths(chains)),
  iteration_id = unlist(lapply(chains, seq_along), use.names = FALSE))
history_input <- postrank_mdomain_input(
  make_states(cbind(z, z), paste0("markov-", seq_along(z))), targets = targets,
  provenance = list(input_id = "tiny-markov-history", law_id = "tiny-markov-law",
    proper_law = TRUE,
    joint_generation = "Both domains use the same synthetic binary chain state.",
    retention = list(warmup_removed = 0L, thinning = 1L),
    sampling_assumptions = list(sampler = "Two-state Markov transition simulator.",
      chain_details = "Lengths 24 and 31; stationary initial draws; seed 1202.",
      target_assertion = "Stationary reversal probability 1/5 by the specified transitions.")),
  representation = "mcmc_equal_weight_draws", state_origin = history)
fixed_grades <- matrix(c(1L, 2L, 1L, 2L), 2L,
  dimnames = list(units, domains))
assessment <- postrank_mdomain_assess(history_input, fixed_grades, policy,
  method = "mcmc", batch_size = 10L,

Use hit counts, long zero runs and batch-to-batch variation to inspect how well a run has explored the event relevant to the fixed report. A zero-hit history is different from a structurally impossible event. Unequal chain rates must be combined using their retained state counts; a simple average of their rates changes the empirical measure. Batch rates are descriptive and are not independent replicates. This route does not supply an iid binomial certificate, a convergence proof, or a held-out interpretation. See ?postrank_mdomain_assess for the separate fixed-sample iid route and its required design record, and vignette("mdomain-quickstart") for the input-to-report workflow.
