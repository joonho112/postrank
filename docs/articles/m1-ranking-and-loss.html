Posterior ranking, integer grades, and reporting loss

Source: vignettes/m1-ranking-and-loss.Rmd
m1-ranking-and-loss.Rmd

Suppose you already have a posterior distribution for one score or outcome per entity—such as schools, employers, or counties—and want to publish ordered integer grades (1, 2, ...). This article defines the single-criterion reporting loss minimized by postrank(), shows why pair-by-pair probability thresholds need not form valid grades, and relates the loss to the report-card objective of Kline, Rose, and Walters (2024).

For a practical walkthrough on example data, start with Getting started: grading with one or two criteria. Every calculation below uses a small four-state distribution directly in R and needs no optimization solver.

Targets and integer grades

Let θi\theta_i be the target quantity for entity i∈{1,…,n}i \in \{1, \dots, n\}, oriented before grading so that larger values receive higher reporting priority. Depending on the study, higher priority can mean better performance or greater need for support. Your statistical model supplies a joint posterior distribution for (θ1,…,θn)(\theta_1, \dots, \theta_n) given the data and model assumptions.

A grading assigns each entity an integer grade gi∈{1,…,G}g_i \in \{1, \dots, G\}:

  • Grade 1 has the highest priority. Giving gi<gjg_i < g_j reports entity ii ahead of entity jj (called a disclosed pair in console output).
  • A shared grade leaves the pair unordered. Giving gi=gjg_i = g_j withholds any ordering claim between ii and jj; it does not claim that θi=θj\theta_i = \theta_j or that the two entities are practically equivalent.

Occupied grade numbers are renumbered to consecutive integers 1, ..., G by canonical_postrank_grade(), which leaves every pair relation unchanged.

With nn entities there are M=(n2)=n(n−1)/2M = \binom{n}{2} = n(n - 1)/2 unordered pairs. Let N(g)N(g) be the number of pairs placed in different grades. Each ordered pair has one reported direction (gi<gjg_i < g_j), so summing over ordered indices (i,j)(i, j) counts each ordered pair once:

eij=Pr⁡(θi≤θj),E(g)=∑i≠j𝟏{gi<gj}eij. e_{ij} = \Pr(\theta_i \le \theta_j), \qquad E(g) = \sum_{i \ne j} \mathbf{1}\{g_i < g_j\} \, e_{ij}.

Here eije_{ij} is the posterior probability that placing ii ahead of jj is wrong, and E(g)E(g) is the posterior expected number of wrong-direction pairs across the report. Standard postrank inputs assume zero posterior probability of exact equality between distinct entities (Pr⁡(θi=θj)=0\Pr(\theta_i = \theta_j) = 0), so eij+eji=1e_{ij} + e_{ji} = 1; the diagonal i=ji = j is not a pair comparison. When exact ties can occur with positive probability, see Exact ties in the posterior versus withheld comparisons.

Directional-error and withholding loss

Reporting a pair in the wrong order costs 1, and leaving a pair unordered costs τ\tau. Averaging over all MM unordered pairs gives the posterior expected loss (risk in package output):

Rτ(g)=E(g)+τ{M−N(g)}M. R_\tau(g) = \frac{E(g) + \tau\{M - N(g)\}}{M}.

postrank accepts 0<τ≤1/20 < \tau \le 1/2. Smaller values of τ\tau make leaving uncertain pairs unordered cheaper relative to risking a wrong direction. In postrank() and postrank_settings(), tau defaults to 0.25 and G_max defaults to 4L as package convenience values when omitted, but τ\tau is a substantive reporting preference rather than a property of the posterior, a confidence level, or a per-pair error cap. Limiting the report to at most G_max grades restricts which gradings are allowed without changing the loss formula.

Different columns in get_profile() and postrank_evaluate() use different denominators:

  • E_over_M divides expected wrong-direction errors E(g)E(g) by all MM pairs.
  • E_over_N divides E(g)E(g) by the N(g)N(g) ordered (disclosed) pairs, giving the expected number of wrong-direction errors per reported pair when N(g)>0N(g) > 0.
  • risk is Rτ(g)R_\tau(g), which adds the withholding cost τ{M−N(g)}/M\tau\{M - N(g)\}/M to E_over_M.

Assigning every entity to Grade 1 leaves all MM pairs unordered: N=0N = 0, the loss is Rτ(g)=τR_\tau(g) = \tau, and E_over_N is NA because its denominator is zero. That single-grade report is a valid grading, distinct from a solver run that failed to return a checked grading.

For one pair (i,j)(i, j) considered in isolation, the three possible pair actions have posterior expected costs:

Pair action Posterior expected cost
Report ii ahead of jj eije_{ij}
Report jj ahead of ii eji=1−eije_{ji} = 1 - e_{ij}
Leave the pair unordered τ\tau

When τ<1/2\tau < 1/2, ordering ii ahead of jj has strictly smaller expected cost than leaving the pair unordered whenever eij<τe_{ij} < \tau (equivalently Pr⁡(θi>θj)>1−τ\Pr(\theta_i > \theta_j) > 1 - \tau); at eij=τe_{ij} = \tau ordering and withholding tie, and at eij=eji=τ=1/2e_{ij} = e_{ji} = \tau = 1/2 all three actions have cost 1/21/2. Applying that threshold pair by pair, however, need not produce a valid set of integer grades.

Pairwise thresholds versus valid grades

Consider three fictional entities A, B, and C whose joint posterior puts exact rational probabilities on four strict orderings, with no exact ties:

library(postrank)

states <- rbind(
  ABC = c(A = 3, B = 2, C = 1),
  ACB = c(A = 3, B = 1, C = 2),
  BAC = c(A = 2, B = 3, C = 1),
  CBA = c(A = 1, B = 2, C = 3)
)
mass_numerator <- c(12L, 3L, 3L, 2L)
probability <- mass_numerator / 20
knitr::kable(data.frame(State = rownames(states), states,
  Probability = probability), row.names = FALSE)

ACB 3 1 2 0.15

Summing the state probabilities where entity i does not exceed entity j gives the pairwise directional-error probabilities eije_{ij}:

ids <- colnames(states)
error <- matrix(NA_real_, 3, 3, dimnames = list(ids, ids))
for (i in 1:3) for (j in setdiff(1:3, i))
  error[i, j] <- sum(probability * (states[, i] <= states[, j]))
pairs <- data.frame(
  Direction = c("A ahead of B", "B ahead of C", "A ahead of C"),
  Error = error[cbind(c(1, 2, 1), c(2, 3, 3))]
)
knitr::kable(pairs, row.names = FALSE)
Direction Error
A ahead of B 0.25
B ahead of C 0.25
A ahead of C 0.10

Suppose τ=1/5=0.20\tau = 1/5 = 0.20. The isolated-pair rule leaves (A, B) and (B, C) unordered because their smaller directional-error probabilities are 5/20=0.25>0.205/20 = 0.25 > 0.20, yet orders A ahead of C because eAC=2/20=0.10<0.20e_{AC} = 2/20 = 0.10 < 0.20. No integer grades can represent both gA=gBg_A = g_B and gB=gCg_B = g_C while also having gA<gCg_A < g_C: shared grades are transitive.

Kline, Rose, and Walters (2024, Section II.E, Example 1, pp. 2481–2482) show the same conflict using three firms with independent normal beliefs and λ=1/4\lambda = 1/4 (an 80% pairwise threshold, matching τ=0.20\tau = 0.20). Our four-state distribution reproduces that conflict with exact rational numbers; see Lee (2026), Chapter 10, Withholding a pair and constructing a common grade.

Enumerating all 13 valid gradings

With three entities, there are 13 valid integer gradings once occupied grades are numbered consecutively (1, 1..2, or 1..3):

actions <- as.matrix(expand.grid(A = 1:3, B = 1:3, C = 1:3))
keep <- apply(actions, 1, function(g)
  identical(sort(unique(as.integer(g))), seq_len(max(g))))
actions <- actions[keep, , drop = FALSE]
nrow(actions)
#> [1] 13

For each grading, we can sum wrong-direction indicators directly over the four posterior states using integer numerators (so rational ties are exact, without relying on independence across pairs or an optimization solver):

tau <- 1 / 5
lambda <- tau / (1 - tau)
counts <- function(g) {
  disclosed <- outer(g, g, "<")
  wrong <- apply(states, 1, function(theta)
    sum(disclosed & outer(theta, theta, "<=")))
  N <- sum(disclosed)
  E_num <- sum(mass_numerator * wrong)
  c(N = N, E_num = E_num, risk_num = 5 * E_num + 20 * (3 - N),
    krw_num = 4 * E_num - (20 * N - E_num))
}
exact <- t(apply(actions, 1, counts))

Sorting the 13 gradings by their posterior expected loss Rτ(g)R_\tau(g) shows two tied optima:

risk <- exact[, "risk_num"] / 300
krw_risk <- exact[, "krw_num"] / 240
best <- which(exact[, "risk_num"] == min(exact[, "risk_num"]))
result <- data.frame(
  Grades = apply(actions, 1, paste, collapse = "/"),
  N = exact[, "N"], E = exact[, "E_num"] / 20,
  E_over_N = ifelse(exact[, "N"] > 0, exact[, "E_num"] / (20 * exact[, "N"]), NA_real_),
  Risk = risk
)

Both 1/1/2 and 1/2/2 minimize expected loss at 11/60≈0.183311/60 \approx 0.1833. Each orders N=2N = 2 of the M=3M = 3 pairs, incurs expected wrong-direction count E=7/20=0.35E = 7/20 = 0.35, and has E_over_N equal to 7/40=0.1757/40 = 0.175. Grading 1/1/2 orders B ahead of C, while 1/2/2 orders A ahead of B; each of those pairs has error probability 1/4=0.25>τ=0.201/4 = 0.25 > \tau = 0.20. Because grades must be transitive, an optimal grading can order a pair whose individual error probability exceeds τ\tau.

The infeasible pair-by-pair threshold pattern (A ahead of C only) would have average cost (2/20+0.20+0.20)/3=1/6≈0.1667(2/20 + 0.20 + 0.20)/3 = 1/6 \approx 0.1667, which lies 1/601/60 below the minimum over valid gradings. That unconstrained pair average is a lower bound that no valid grading can reach. Moreover, because 1/1/2 and 1/2/2 tie at 11/6011/60, returning a single optimal grading does not mean there is a unique optimum.

Passing error to postrank_probabilities() and scoring each grading with postrank_evaluate() reproduces the exact losses:

input <- postrank_probabilities(
  error, criterion = "priority", event = "directional_error",
  zero_ties = TRUE, margin = 0,
  source = list(
    kind = "analytic_reference",
    description = "Four-state distribution with probabilities 12/20, 3/20, 3/20, 2/20",
    conditioning = "Fixed four-state target distribution in m1-ranking-and-loss"
  ),
  targets = c(priority = "Fictional target; larger means higher priority")
)
evaluated <- apply(actions, 1, function(g)
  postrank_evaluate(setNames(g, ids), input,
    weights = c(priority = 1), tau = tau)[["primary_risk"]])
max(abs(evaluated - risk))
#> [1] 1.110223e-16

postrank_evaluate() scores any supplied integer grade vector; it does not check whether the grading obeys a G_max, exact_G, or q constraint (here all 13 three-entity gradings are unrestricted).

Whenever the single-grade report 1/1/.../1 (loss τ\tau) belongs to the allowed set of gradings and g*g^* minimizes Rτ(g)R_\tau(g) over that set,

Rτ(g*)≤τ⇒E(g*)≤τN(g*). R_\tau(g^*) \le \tau \quad \Longrightarrow \quad E(g^*) \le \tau \, N(g^*).

When N(g*)>0N(g^*) > 0, the average expected wrong-direction rate among ordered pairs satisfies E(g*)/N(g*)≤τE(g^*)/N(g^*) \le \tau (here 7/40=0.175≤0.207/40 = 0.175 \le 0.20). Requiring exact_G with two or more occupied grades removes 1/1/.../1 from the allowed set, so that bound need not hold. Nonzero solver gaps and Monte Carlo error also require separate accounting, and the inequality applies to the supplied posterior rather than guaranteeing calibration under an unknown true population distribution.

Correspondence with Kline, Rose, and Walters (2024)

In Section II of Kline, Rose, and Walters (2024) (pp. 2477–2482, equations 1–6), a report card assigns each firm a grade di∈{1,…,n}d_i \in \{1, \dots, n\} in which larger did_i indicates more discrimination—the reverse of postrank’s convention where Grade 1 has highest priority. Reversing occupied grade numbers via di=G+1−gid_i = G + 1 - g_i produces the exact same ordered and unordered pair relations.

For each unordered pair, Kline, Rose, and Walters give payoff +λ+\lambda (λ∈[0,1]\lambda \in [0, 1]) for ordering the pair in the right direction, −1-1 for ordering it in the wrong direction, and 00 for assigning the same grade. Negating payoffs and averaging over all M=(n2)M = \binom{n}{2} pairs gives the compound loss

LK,λ(g,θ)=D<(g,θ)−λC(g,θ)M, L_{K,\lambda}(g, \theta) = \frac{D_{<}(g, \theta) - \lambda \, C(g, \theta)}{M},

where D<(g,θ)D_{<}(g, \theta) counts strictly wrong ordered pairs and C(g,θ)C(g, \theta) counts strictly right ordered pairs, with Bayes risk RK,λ(g)=𝔼[LK,λ(g,θ)]R_{K,\lambda}(g) = \mathbb{E}[L_{K,\lambda}(g, \theta)].

When Pr⁡(θi=θj)=0\Pr(\theta_i = \theta_j) = 0 for every distinct pair, D<(g,θ)+C(g,θ)=N(g)D_{<}(g, \theta) + C(g, \theta) = N(g). Substituting C(g,θ)=N(g)−D<(g,θ)C(g, \theta) = N(g) - D_{<}(g, \theta) connects the two parameters and objectives by a positive affine transformation:

λ=τ1−τ,τ=λ1+λ,Rτ(g)=τ+(1−τ)RK,λ(g). \lambda = \frac{\tau}{1 - \tau}, \qquad \tau = \frac{\lambda}{1 + \lambda}, \qquad R_\tau(g) = \tau + (1 - \tau) \, R_{K,\lambda}(g).

Because 1−τ>01 - \tau > 0 for all τ∈(0,1/2]\tau \in (0, 1/2], Rτ(g)R_\tau(g) and RK,λ(g)R_{K,\lambda}(g) share the exact same set of minimizers over any nonempty candidate family of gradings when evaluated on the same posterior, entities, and target orientation. Pair errors do not need to be independent.

max(abs(risk - (tau + (1 - tau) * krw_risk)))
#> [1] 5.551115e-17
identical(best, which(exact[, "krw_num"] == min(exact[, "krw_num"])))
#> [1] TRUE
c(tau = tau, lambda = lambda)
#>    tau lambda 
#>   0.20   0.25

Notice the parameter conversion: Kline, Rose, and Walters’s benchmark choice λ=0.25\lambda = 0.25 (an 80% isolated-pair threshold) corresponds to τ=0.25/1.25=0.20\tau = 0.25 / 1.25 = 0.20, whereas postrank’s convenience default tau = 0.25 corresponds to λ=1/3\lambda = 1/3 (a 75% isolated-pair threshold). RK,λ(g)R_{K,\lambda}(g) can also take negative values because it subtracts λ\lambda times expected right-direction pairs, whereas Rτ(g)R_\tau(g) lies in [0,1][0, 1]. See Lee (2026), Chapter 10, Scalar normalization and withholding cost, for the step-by-step derivation.

At the boundary τ=0\tau = 0 (λ=0\lambda = 0), withholding is free; postrank requires τ>0\tau > 0. At τ=1/2\tau = 1/2 (λ=1\lambda = 1), a 50/50 pair has expected cost 1/21/2 whether ordered in either direction or left unordered, so a fine grading at τ=1/2\tau = 1/2 does not imply strong posterior support for its reported directions.

If exact ties have positive posterior probability (Pr⁡(θi=θj)>0\Pr(\theta_i = \theta_j) > 0), strict and weak error counts differ: on a tied draw θi=θj\theta_i = \theta_j, eij=Pr⁡(θi≤θj)e_{ij} = \Pr(\theta_i \le \theta_j) counts an error while both strict counts D<D_< and CC are zero. An extra action-dependent term then enters, and the affine identity above no longer holds without modification; see Exact ties in the posterior versus withheld comparisons.

Comparing optimization procedures

Kline, Rose, and Walters formulate their unrestricted report-card problem as an integer linear program over binary pair indicators (Section II.C, equations 4–5, implemented in their Python drrank package, and replicated in R in Lee’s gradepath package via gradepath::gp_grade()). That unrestricted optimization matches postrank() when both allow up to nn grades (G_max = n), impose no q or exact_G constraint, and use matching parameter values (τ=λ/(1+λ)\tau = \lambda/(1 + \lambda)), target orientation, and pairwise probabilities—including whether any probability floor or rounding was applied before solving.

By contrast, optimizing contiguous cutpoints along a fixed score order (such as posterior means or expected ranks via postrank_cuts()) searches a smaller subset of gradings, and setting G_max < n restricts the allowed family unless imposed in both procedures. When comparing two implementations, compare their ordered pair relations and losses re-evaluated on the same probability array: when multiple gradings tie at the minimum loss, two valid solvers can return different optimal grade vectors without disagreeing on the minimum risk.
