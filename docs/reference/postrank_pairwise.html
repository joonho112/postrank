Calculate Directional-Error Probabilities

postrank_pairwise.Rd

Posterior draws or a specified finite law are aggregated into comparison probabilities for one or several criteria. For distinct entities, eij,k=P(θi,k≤θj,k)e_{ij,k}=P(\theta_{i,k}\leq\theta_{j,k}) is the error for reporting entity i above entity j, with larger target values having higher priority. Diagonal entries are NA because self-comparisons are unused.

Usage 

postrank_pairwise(draws, method = c("blocks", "reference"), block_size = 128L)

Arguments

draws

An object from postrank_draws() or as_postrank_draws(), a supported canonical input payload, or already calculated coefficients from postrank_gaussian_coefficients(), postrank_mixture_coefficients(), or postrank_probabilities(). For already calculated inputs, omit method and block_size.

method

For Monte Carlo draws, "blocks" (default) aggregates bounded blocks of ordered pairs; "reference" aggregates one pair at a time. Both use equal-weight empirical frequencies and preserve the input draws. Exact finite laws instead use their declared masses.

block_size

Positive integer maximum ordered-pair block size for the block algorithm. It changes working storage, not the probability event.

Value

For draw or finite-law input, a postrank_pairwise object containing the directional-error array e, criterion-specific sample_sizes, and source records. Exact finite laws also retain rational coefficients and a floating-point projection, with sample sizes marked unavailable. Already calculated coefficient or probability inputs are validated and returned unchanged, with their original class and source information.

Details

The ordinary route requires zero equality probability for each pair of distinct entities. Continuity of every marginal is neither necessary nor sufficient: a finite law with no pairwise equality is admissible, whereas identical continuous targets have equality probability one. Use postrank_tie_pairwise() for the separate equality-neutral loss when genuine equality is present. With zero equality, reverse off-diagonal probabilities sum to one.

For IID or MCMC output, a frequency of zero or one does not establish that the underlying posterior event is impossible or certain. A declared exact finite law instead defines the probabilities through its complete states and masses; it requires the optional gmp package for exact arithmetic.

Criterion-wise inputs retain each criterion's own draw count and history. Within a criterion, all entity values must refer to the same state. The resulting coefficients suffice for additive expected risk, but separate criterion blocks do not establish a cross-criterion joint trace for composite-score or simultaneous-event calculations.

See also
