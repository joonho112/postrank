The Three-Criterion Example's Gaussian Law

pr_example_gaussian.Rd

The frozen law behind pr_example_draws as a postrank_coefficients object built by postrank_gaussian_coefficients(), with the explicit declaration "entities_given_shared_h" and the six strict provenance fields (input_payload_sha256 hashes the frozen law file, source_sha256 the law generator source and config_sha256 the generation configuration). Analytic directional errors and marginal summaries describe this same law. The finite sample in pr_example_draws approximates it and need not give exactly the same coefficients or grades. See pr_tutorial for a smaller one-criterion example and postrank_problem() for native mode restrictions.

Usage

pr_example_gaussian

Format

A postrank_coefficients object (source$kind = "gaussian_conditional"): means 30 x 3, e 30 x 30 x 3, source$covariance 3 x 3 x 30 (criterion_i, criterion_j, entity), plus provenance, capabilities and identities.

Source

data-raw/make-pr-example-gaussian.R.

Examples

dim(pr_example_gaussian$e)
#> [1] 30 30  3
postrank_coefficient_capabilities(pr_example_gaussian)$weighted_expected_risk
#> [1] TRUE
