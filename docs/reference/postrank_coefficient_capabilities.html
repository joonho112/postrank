Check Which Operations a Conditional-Law Input Supports

postrank_coefficient_capabilities.Rd

postrank_coefficient_capabilities() validates a normal or shared-state mixture posterior input and returns logical flags telling which postrank functions and settings accept it.

Usage

postrank_coefficient_capabilities(x)

Arguments

x

A postrank_coefficients object from postrank_gaussian_coefficients() or postrank_mixture_coefficients().

Value

A named list of 12 logical flags:

  • weighted_expected_risk, posterior_means and weighted_at_most_G_problem: TRUE;

  • minimax_problem, protection_problem (q) and exact_G_problem (in postrank_problem()): FALSE;

  • target_state_trace, target_quantiles (empirical draw quantiles), exact_rational and formal_numerical_certification: FALSE;

  • rb_conditional_risk_trace: TRUE for mixtures, FALSE for a single normal posterior;

  • hyperparameter_mcse_eligible: TRUE only for mixtures with source_regime == "hyperparameter_mcmc".

Details

exact_G_problem = FALSE applies to unrestricted optimization in postrank() and postrank_problem(); fixed-order cuts in postrank_cuts() do allow exact_G on postrank_coefficients. hyperparameter_mcse_eligible = TRUE indicates that postrank_coefficient_diagnose() can compute MCMC metrics if valid chain_history records are supplied, not that sampling converged.

See also

postrank_gaussian_coefficients(), postrank_mixture_coefficients(), postrank_coefficient_diagnose(), validate_postrank_coefficients()

Examples

caps <- postrank_coefficient_capabilities(pr_tutorial$one)
caps[c("weighted_expected_risk", "weighted_at_most_G_problem",
  "minimax_problem", "rb_conditional_risk_trace")]
#> $weighted_expected_risk
#> [1] TRUE
#> 
#> $weighted_at_most_G_problem
#> [1] TRUE
#> 
#> $minimax_problem
#> [1] FALSE
#> 
#> $rb_conditional_risk_trace
#> [1] FALSE
#>
