Stored Example Results

postrank_example.Rd

postrank_example() reads results stored with the package. Call it without arguments to list the examples or give a name to load one. Reading an example needs no solver.

Usage

postrank_example(name = NULL)

Arguments

name

Name of a stored result, as listed by postrank_example(). If NULL (the default), the list is returned instead.

Value

With name = NULL, a data frame with one row per stored result and the columns

  • name and description;

  • class: the class of the stored object;

  • call: an example call describing the calculation;

  • computed_with: the postrank and solver versions that were used;

  • solves: how many optimization problems were solved (0 for comparisons of stored results);

  • created: when it was computed (UTC).

Otherwise the stored object, for example a postrank_analysis, with its grades and numerical results. Local solver installation paths were replaced with portable labels when saving.

Details

The grading analyses used postrank 1.1.0 and HiGHS. The two comparison examples summarize stored analyses. Some example calls are abbreviated or refer to another stored result, such as tutorial_two. In the calls for toy_minimax and toy_frontier, w stands for c(need_A = 0.6, need_B = 0.4).

Before a result is returned, postrank checks that the stored file is unchanged (its size and SHA-256 checksum) and that this version of postrank can read it. Reading a result never runs a solver and never changes the stored files.

See also

get_grades(), get_risk(), postrank()
