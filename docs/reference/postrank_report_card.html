Prepare an Entity Report Card with Posterior Intervals

postrank_report_card.Rd

postrank_report_card() combines a checked grading with marginal posterior means, central intervals and expected ranks in an entity-level table. Each row gives an entity's grade, how many other entities are reported above it, below it or in the same grade, and per-criterion posterior summaries. For a basic two-column grade table, use postrank_tables.

Usage 

postrank_report_card(
  x,
  draws = NULL,
  level = 0.9,
  order = c("expected_rank", "mean", "label"),
  order_by = NULL
)

Arguments

x

A postrank_fit or postrank_analysis object with a checked grading (incumbent_validated = TRUE; otherwise stops with no_validated_incumbent).

draws

Optional posterior input matching x's input_identity: a postrank_draws, postrank_coefficients, or postrank_probabilities() object with marginal interval summaries. Required when x is a postrank_fit built from a postrank_pairwise object that does not store the original draws.

level

Central posterior interval level in (0, 1) (default 0.90). For a postrank_probabilities() input with supplied intervals, level must equal the stored summaries$level.

order

Secondary sort order within each grade: "expected_rank" (weighted expected rank, the default), "mean" (descending posterior mean on one criterion) or "label" (entity ID).

order_by

Criterion ID used when order = "mean" (required when several criteria are present, optional with one; must be NULL for other order values).

Value

A postrank_report_card object with the full data frame in data, plus level, interval_source, secondary_order, settings, grade_identity, input_identity, schema_version, provenance (recording ordering_criterion when order = "mean") and warnings.

Details

Rows are sorted first by grade (grade 1 is highest priority; shared grades leave pairs unordered), then by order, with entity_id breaking remaining ties. In data, n_above counts entities graded below this entity (grade[i] < grade[j]), n_below counts entities graded above it, and n_withheld counts other entities sharing its grade; for every row, n_above + n_below + n_withheld == n - 1. Per-criterion columns are named mean_<k>, lower_<k>, upper_<k> and expected_rank_<k>, where expected rank is 1+∑j≠ieij,k1 + \sum_{j \ne i} e_{ij,k}. When order = "expected_rank", rows within a grade are ordered by weighted expected rank rather than adding means across criteria in different units.

Cached summaries on a postrank_analysis at the requested level are reused; otherwise summaries are computed from the posterior source without re-solving for grades. Intervals summarize marginal target uncertainty (a posterior mean can lie outside an equal-tail interval), not Monte Carlo error or the probability that a grade assignment is right. data always retains all n entities; row caps in postrank_plot_report_card() affect only the plot.

See also

postrank(), postrank_tables, postrank_plot_report_card(), postrank_posterior_means()
