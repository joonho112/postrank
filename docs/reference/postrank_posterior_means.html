Posterior Means and Intervals per Entity and Criterion

postrank_posterior_means.Rd

Marginal posterior means are returned as a matrix. When level is supplied, central equal-tail intervals are added for the same oriented targets. These are marginal target summaries rather than simultaneous bands or intervals for grade numbers.

Usage 

postrank_posterior_means(x, level = NULL)

Arguments

x

A postrank_draws, postrank_coefficients, or postrank_probabilities object with supplied marginal summaries.

level

NULL for means only, or a central interval level in (0, 1). A probability input with retained intervals supports only its supplied level; NULL can still request its supplied means without intervals.

Value

An n x K numeric matrix with dimnames entity and criterion; when level is given it carries attributes lower, upper, level and interval_source.

Details

Draw inputs use equal-weight means and stats::quantile(type = 7); an exact finite law uses probability-weighted means and the generalized inverse Q(p)=inf⁡{x:F(x)≥p}Q(p) = \inf\{x : F(x) \ge p\}; Gaussian coefficients use their stored means and analytic quantiles; a shared-state mixture uses its stored means and a bracketed root of the marginal mixture CDF in standardized coordinates. Mixture endpoints are checked against their CDF with absolute probability tolerance 1e-10; a numerically unrepresentable endpoint raises posterior_quantile_failure. Stored mixture weights are never changed. Means and quantiles are computed separately, so a mean may lie outside its central interval for a skewed law. A pairwise error array alone does not determine posterior means, so postrank_pairwise objects are not accepted. Inputs from postrank_probabilities() can return explicitly supplied marginal summaries. Those values are not inferred from the probabilities, and their fixed interval level cannot be changed.

postrank_report_card()
