Compute Comparisons from a Conditional Gaussian Law

postrank_gaussian_coefficients.Rd

postrank_gaussian_coefficients() computes pairwise directional-error probabilities analytically from entity posterior means and within-entity covariance matrices under a normal (Gaussian) posterior, without simulating draws. For distinct entities i and j on criterion k, eij,k=P(θi,k≤θj,k)e_{ij,k} = P(\theta_{i,k} \le \theta_{j,k}) is the probability that reporting i above j is in the wrong order (diagonal entries are NA).

Usage 

postrank_gaussian_coefficients(
  means,
  covariance,
  conditional_independence,
  provenance
)

Arguments

means

Finite plain numeric n x K matrix (n >= 2, K >= 1) with named dimnames: list(entity = entity_ids, criterion = criterion_ids). Larger values must already mean higher priority toward grade 1.

covariance

Finite symmetric positive-definite plain numeric K x K x n array with named dimnames: list(criterion_i = criterion_ids, criterion_j = criterion_ids, entity = entity_ids). Each K x K slice gives within-entity covariance across criteria (positive variance when K = 1) and must satisfy exact symmetry S == t(S) with zero tolerance (symmetrize (V + t(V)) / 2 beforehand if needed); cross-entity covariance cannot be encoded here, and singular or asymmetric matrices stop the call without repair.

conditional_independence

Must be "entities_given_shared_h", an explicit model declaration (not inferred from marginal moments) stating that entities are conditionally independent given the fixed conditioning state.

provenance

Plain named list of non-empty character strings: producer_id, producer_version, posterior_id, input_payload_sha256, source_sha256 and config_sha256, plus optional model_sha256. Every *_sha256 entry must be a 64-character lowercase hexadecimal SHA-256 digest.

Value

A postrank_coefficients object (input_kind = "gaussian_conditional") containing entity_ids, criterion_ids, means, the n x n x K directional-error array e, source, provenance, capabilities, validation, coefficient_identity, input_identity, pairwise_identity, and schema_version ("coefficient-0.1.0").

Details

Each off-diagonal probability is computed directly in the lower tail of the normal distribution from (means[j, k] - means[i, k]) / sqrt(v_i + v_j) to preserve small tail values; positive variances and conditional independence across entities imply zero probability of exact equality. These are ordinary floating-point analytic calculations, not exact rational arithmetic or interval-verified bounds.

In postrank() and postrank_problem(), normal posterior coefficients support the weighted expected-loss objective with G_max (minimax, q error budgets and exact_G are not available there; see postrank_coefficient_capabilities()). If an empirical-Bayes prior is held fixed, these probabilities condition on that estimate; to average over hyperparameter states, use postrank_mixture_coefficients() rather than moment-matching to a single normal distribution. postrank does not fit the model or verify provenance hashes against external files.

See also

postrank_mixture_coefficients(), validate_postrank_coefficients(), postrank_coefficient_capabilities(), postrank_coefficient_diagnose()

Examples 

law <- pr_tutorial$law
x <- postrank_gaussian_coefficients(
  means = law$means[, "score_A", drop = FALSE],
  covariance = law$covariance["score_A", "score_A", , drop = FALSE],
  conditional_independence = "entities_given_shared_h",
  provenance = pr_tutorial$one$provenance)
