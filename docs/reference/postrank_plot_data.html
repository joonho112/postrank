Extract Stored Data for a Figure

postrank_plot_data.Rd

postrank_plot_data() returns the complete data frame (or named list of data frames) underlying the seven postrank plot types without solving, evaluating gradings, or recomputing posterior summaries. Plot display caps (max_rows, max_entities) and label maps do not filter or rename the returned tables.

Usage

postrank_plot_data(x, which = NULL)

Arguments

x

A postrank_analysis, postrank_fit, postrank_report_card, postrank_baseline, postrank_frontier, postrank_commonality_cost, postrank_comparison, postrank_pairwise (including postrank_probabilities()), or postrank_coefficients.

which

Optional single string naming the component to extract. For a postrank_analysis, NULL returns a named list of "report_card", "relations", and "profile", or pass one of "report_card", "relations", "profile", or "pairwise". See Details for other classes.

Value

A data frame, a named list of three components (with an "availability" attribute) when x is a postrank_analysis and which = NULL, or NULL when a requested "report_card" or "relations" table has no underlying report card or checked grading. When profile is requested without a checked grading, returns the zero-row data frame from get_profile().

Details

Accepted which values by input class:

  • postrank_analysis: NULL returns list(report_card = ..., relations = ..., profile = ...) whose "availability" attribute gives list(available, reason) for each slot; "pairwise" must be requested by name because its table has n * n * K rows.

  • postrank_fit: defaults to "relations" and also accepts "profile" or "pairwise".

  • postrank_report_card: returns the long report-card table.

  • postrank_baseline: returns the pair-relations table.

  • postrank_frontier and postrank_commonality_cost: return x$table.

  • postrank_comparison: returns x$table by default, or x$relations when which = "relations".

  • postrank_pairwise and postrank_coefficients: accept NULL or "pairwise" and return the pairwise probability table (aggregate raw postrank_draws with postrank_pairwise() first).

Returned columns for reshaped views:

  • report_card: entity_id, grade, sort_rank, n_withheld, criterion, mean, lower, upper, and expected_rank, stacked by criterion in stored card order (interval level and interval_source stay on the postrank_report_card object).

  • relations: one row per unordered pair (i_pos < j_pos) in grade-then-ID order with entity_i, entity_j, i_pos, j_pos, integer code (1L = "above", 0L = "withheld", -1L = "below"), and factor relation.

  • profile: same columns as get_profile().

  • pairwise: entity_i, entity_j, criterion, and error_probability (n * n * K rows in input order with entity_i varying fastest, including NA diagonal entries; available even when a fit has no checked grading).

Passing which equal to "sensitivity", "fragility", "crossfit", "trace", or "dispersion" stops with condition code "unshipped_figure"; those figure names are not implemented as plot views, although the numerical functions postrank_sensitivity(), postrank_mc_fragility(), and postrank_crossfit() are available.

See also

postrank_plot_report_card(), postrank_plot_relations(), postrank_plot_pairwise(), get_profile()
