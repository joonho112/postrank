Extract Stored Data for a Figure

postrank_plot_data.Rd

The complete data underlying the seven postrank figure types are returned for inspection or alternative displays. Stored results are read and reshaped without optimization, action evaluation or calculation of posterior summaries. Plot row limits and display labels do not affect the returned tables.

Usage

postrank_plot_data(x, which = NULL)

Arguments

x

A postrank_analysis, postrank_fit, postrank_report_card, postrank_baseline, postrank_frontier, postrank_commonality_cost, postrank_comparison, or prepared pairwise/coefficient input.

which

Optional component name. Analysis components are "report_card", "relations" and "profile"; "pairwise" explicitly requests prepared probabilities. See Details for other classes.

Value

A data frame, a named list for an analysis with which = NULL, or NULL for an unavailable card or relation component. A profile without a validated incumbent is an empty typed data frame. The analysis list has an availability attribute with an available flag and reason per component.

Details

For an analysis, which = NULL returns report_card, relations and profile. Pairwise probabilities are deliberately separate because the complete table has n * n * K rows. A fit defaults to "relations" and also accepts "profile" or "pairwise". A report card returns its long table; a baseline returns its relations. Frontier and commonality objects return their stored tables. A comparison returns its summary table by default and its change-count table for which = "relations".

The report-card table has entity_id, grade, sort_rank, n_withheld, criterion, mean, lower, upper and expected_rank. Rows are grouped by criterion and follow stored card order within each criterion; interval level and source remain on the card object. Relations contain one row per unordered pair with entity_i, entity_j, i_pos, j_pos, code and relation, in grade-then-ID order. Code 1 means the first entity is above the second, 0 means withheld and -1 means below. Profile columns are listed in get_profile().

which = "pairwise" returns entity_i, entity_j, criterion and error_probability, including the NA diagonal. It preserves input ID order, with entity_i varying fastest. This component remains available for fits without a validated grade. Prepared pairwise/probability/coefficient objects return it by default, but raw draws must first be aggregated with postrank_pairwise(). The table is not a relation-change map; use postrank_plot_relations() with two actions for that view.

The designs "sensitivity", "fragility", "crossfit", "trace" and "dispersion" are reserved and raise unshipped_figure. This does not imply that all similarly named numerical diagnostic functions are unavailable.

See also

postrank_plot_report_card(), postrank_plot_relations(), postrank_plot_pairwise(), get_profile()

Examples

# Read prepared tutorial results; no model fitting or optimization.
source(system.file("scripts", "_vignette-setup.R", package = "postrank"),
  local = TRUE)
one <- load_or_compute("tutorial_one")
card_data <- postrank_plot_data(one, "report_card")
